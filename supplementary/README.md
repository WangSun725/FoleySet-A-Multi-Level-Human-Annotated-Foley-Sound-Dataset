# Supplementary Tables

This directory contains the complete supporting tables for the FoleySet paper:

1. [Keyword-to-category mapping for the Foley taxonomy](keyword_to_category_mapping.md)
   ([CSV](keyword_to_category_mapping.csv))
2. [Per-class results for 73-way sub-category classification](subcategory_classification_results.md)
   ([CSV](subcategory_classification_results.csv))

The Markdown files are intended for convenient viewing on GitHub. The CSV files
provide the same information in a machine-readable format.
